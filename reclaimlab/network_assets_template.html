Privacy & interpretation

URLs, headers, cookies, payloads, query strings, private paths and absolute timestamps are excluded by the HAR analysis. No resource is fetched, replayed or executed. This self-contained report has no external scripts, images, fonts or uploads.

Response-body bytes are captured HAR measurements, not decoded memory or guaranteed wire-transfer sizes. HTTP request duration is not rendering time, user input latency or a page-speed score. Kind filters can exclude error responses with different MIME metadata; use a whole-capture error gate when needed.
